- **MTProto**: [grammers](https://codeberg.org/Lonami/grammers): вхід за номером або QR-кодом, 2FA, чати, історія, відповіді, редагування й видалення, оновлення наживо
- **Медіа**: аватарки, фото, стікери з дисковим кешем (`~/.local/share/glassgram/cache`); надсилання файлів і стікерів; голосові та аудіо з хвильовою формою, перемотуванням і швидкістю, панель музичного плеєра з музикою чату як чергою (повтор, перемішування, плейлист) і музикою в профілі; GIF, кружечки й webm-стікери прямо в чаті, відеопрогравач із повним екраном і «картинкою в картинці», який грає великі відео потоком, не чекаючи повного завантаження; запис голосових (потрібен ffmpeg з `ffplay`)
- **Чати**: форуми з темами, коментарі в каналах, папки й архів, закріплення, вимкнення сповіщень, чернетки, статуси «в мережі» та «друкує…»
- **Пошук**: глобальний (поле над списком чатів, із вкладками «Чати», «Канали», «Застосунки», «Публікації» і «Медіа») і в чаті (🔍 у шапці)
- **Форматування**: показ сутностей Telegram і розмітка під час надсилання
- **Повідомлення**: пересилання, вибір кількох, тихе й відкладене надсилання, кнопки ботів, вставка з буфера, прогрес файлів
- **Сповіщення**: системні на Linux, Windows і macOS з кнопками «Відповісти» й «Позначити прочитаним» (Linux, Windows), звуки з рингтонами акаунта й власним звуком чату, лічильник у заголовку вікна, іконка в треї
- **Мови**: українська й англійська вбудовані в код (завжди офлайн), усі мови, які пропонує Telegram Desktop (Налаштування → Мова показує їх із власними назвами, позначкою «бета» і часткою перекладеного; клік завантажує пакет, кешує його й одразу перемикає, без перезапуску), а також файли локалізації (`locales/*.json`, див. нижче)
- **Акаунти**: кілька акаунтів, перемикання в меню під іменем у шапці (`src/accounts.rs`)
- **Налаштування** (⚙): мова, тема (темна, світла, як у системі), масштаб інтерфейсу, сповіщення, автовідтворення, SOCKS5- і MTProto-проксі (кілька, перемикання на льоту, з пінгом), конфіденційність, активні сеанси, локальний пароль; зберігаються в `~/.local/share/glassgram/settings`
- **Розділи налаштувань** як у Telegram Desktop: Мій акаунт (ім'я, біо, юзернейм з перевіркою доступності та його QR-кодом, фото профілю, колір імені й профілю з живим попереднім переглядом, емодзі-статус) · Мої історії (історії, збережені в профілі, альбоми та архів) · Сповіщення · Конфіденційність і безпека · Налаштування чатів · Папки · Додатково · Пристрої · Мова · Мої зірки (баланс та історія з вкладками Усі / Вхідні / Вихідні; клік по операції показує подробиці)
- **Черга надсилання**: текстові повідомлення, файли, голосові й кружечки з'являються одразу (годинник), повторюються без мережі й переживають перезапуск; невдалі отримують червону позначку з «Повторити» / «Видалити»
- **Скло**: справжнє розмиття через wgpu-шейдер (`src/blur.rs`, `src/glass.wgsl`); без wgpu — векторний фолбек
- **UI**: egui / eframe (wgpu), власний рендер скла — `src/glass.rs`

## Встановлення

Готові збірки — на сторінці [Releases](https://github.com/petro-pixel/glassgram/releases); у них уже є
ключі Telegram API та ffmpeg, тож лишається тільки ввійти за номером телефону:
- **Windows**: `Glassgram-<версія>-setup.exe`;
- **Linux**: `Glassgram.flatpak` — `flatpak install --user Glassgram.flatpak`, потім `flatpak run io.github.petro_pixel.Glassgram`.

### Політика підпису коду (Code signing policy)

Безкоштовний підпис коду надає [SignPath.io](https://about.signpath.io/), сертифікат — [SignPath Foundation](https://signpath.org/).
Інсталятор для Windows і `glassgram.exe` збирає й підписує GitHub Actions (`.github/workflows/release.yml`)
з цього репозиторію; вкладений `ffmpeg.exe` — збірка upstream, ми його не підписуємо.

- Автори й рецензенти: [petro-pixel](https://github.com/petro-pixel)
- Затверджують підпис: [petro-pixel](https://github.com/petro-pixel)

Приватність: програма не передає жодної інформації іншим мережевим системам, якщо цього прямо не попросив
користувач або той, хто її встановлює чи запускає. Вона з'єднується лише з серверами Telegram, щоб працював
ваш акаунт, а міні-застосунки ботів і посилання відкриває лише на вашу дію.

## Запуск із коду

```sh
cargo run --release -- --demo   # демо з вигаданими чатами (англійською), без мережі
cargo run --release             # справжній акаунт
```

На Linux для вікон міні-застосунків збірці потрібен WebKitGTK: `sudo apt install libwebkit2gtk-4.1-dev pkg-config`
(`sudo dnf install webkit2gtk4.1-devel` на Fedora, `sudo pacman -S webkit2gtk-4.1` на Arch); використовується версія з репозиторіїв дистрибутива. Windows (WebView2) і macOS (WKWebView) нічого додаткового не потребують.

Збірці з коду потрібні `api_id` та `api_hash` з <https://my.telegram.org> → *API development tools*.
Їх можна ввести у вікні входу або передати через змінні `TG_API_ID` / `TG_API_HASH`. Щоб вбудувати їх
у програму, як у релізах, задайте під час збірки `GLASSGRAM_API_ID` / `GLASSGRAM_API_HASH` (`build.rs`); з `--features no-key-screen`
зникає й екран ключів (без з'єднання застосунок пропонує «Повторити»).

Сесія та облікові дані зберігаються в теці даних: `~/.local/share/glassgram/` на Linux,
`%APPDATA%\glassgram\` на Windows, `~/Library/Application Support/glassgram/` на macOS.

Для голосових, аудіо, відео й запису потрібен ffmpeg (`ffmpeg` і `ffplay`):
- **Linux**: з дистрибутива (`sudo apt install ffmpeg`, `sudo dnf install ffmpeg`…);
- **Windows**: покладіть `ffmpeg.exe` і `ffplay.exe` поруч із `glassgram.exe` або будь-де в `PATH`;
- **macOS**: `brew install ffmpeg`.

На Linux мікрофон береться з PipeWire (`pw-record`), якщо він працює, інакше з PulseAudio;
`GLASSGRAM_AUDIO=pulse` або `GLASSGRAM_AUDIO=pipewire` вибирає примусово. На Windows закриття вікна ховає
Glassgram у трей; вийти — через меню іконки в треї.

Збірки для Windows і macOS компілюються, але на справжніх машинах ще не запускалися.

## Переклади

Українська й англійська живуть у коді. Кожна інша мова — JSON-файл, де ключ — англійський рядок:

```json
{ "@name": "Deutsch", "Cancel": "Abbrechen", "{n} votes": { "one": "{n} Stimme", "other": "{n} Stimmen" } }
```

1. Скопіюйте [locales/template.json](locales/template.json) (усі рядки, порожні значення) у `<код>.json`, наприклад `pl.json`.
2. Заповніть `@name` і перекладіть значення; `{заповнювачі}` лишайте як є. Порожні значення показуються англійською.
   Рядки з числом (`{"one": "", "other": ""}`) мають ті [форми множини CLDR](https://www.unicode.org/cldr/charts/latest/supplemental/language_plural_rules.html),
   що є у вашій мові: `zero`, `one`, `two`, `few`, `many`, `other`.
3. Покладіть файл у теку `locales` поруч із сесією та налаштуваннями (`~/.local/share/glassgram/locales/`)
   і виберіть мову в Налаштування → Мова. Перезбирати не треба.
4. Щоб мова йшла разом із програмою, додайте файл у `locales/` і в `BUILTIN` у `src/i18n.rs`.

Мови зі списку Telegram беруться з translations.telegram.org: їхні пакети мають ключі Telegram Desktop, а
[locales/tdesktop-keys.json](locales/tdesktop-keys.json) зіставляє наші англійські рядки з цими ключами (лише точні збіги за змістом;
`{"key", "args"}` перейменовує заповнювачі; ключі множини на кшталт `lng_xxx#few` вибираються за правилом CLDR мови). Рядок шукається спершу у файлі локалізації, далі в пакеті Telegram, інакше показується англійською.

## Керування

- Права кнопка миші на повідомленні відкриває меню: відповісти, копіювати, редагувати, видалити.
- Подвійний клік — відповісти. Клік по смужці відповіді над полем — процитувати частину повідомлення або відповісти в іншому чаті.
- Esc скасовує відповідь або редагування й закриває панель стікерів.
- 📎 — надіслати файли (або перетягніть чи вставте їх): вікно покаже, що піде, з підписом (текст із поля вводу), «Стиснути зображення», «Приховати під спойлер», «Підпис над медіа» і (одне фото чи відео в особистому чаті) «Одноразовий перегляд»; файли, кинуті на нього, додаються. Перетягнута папка йде zip-архівом; коли елементів кілька, «Надіслати одним архівом» пакує їх в один. Правий клік по 📎: надіслати без стиснення, створити опитування чи вікторину, створити чеклист, а також боти меню вкладень, дозволені в цьому чаті (клік відкриває міні-застосунок бота для чату, правий клік прибирає його з меню); посилання `t.me/<bot>?startattach` спершу пропонує додати туди свого бота. Кнопка «Увійти» під повідомленням бота (або посилання на сайт, що це підтримує) питає «Увійти на <домен> як <ім'я>?», за бажанням дозволяючи ботові писати вам; «Не входити» відкриває звичайну адресу. Клік по пункту чеклиста позначає його; «Результати» під публічним опитуванням показують, хто за що голосував; меню опитування відкликає ваш голос або зупиняє ваше опитування. Фото чи відео під спойлером відкривається кліком. Одноразове чи тимчасове фото або відео показує обкладинку: клік відкриває його один раз, потім воно стає недоступним. Редагуючи фото чи файл («Редагувати» в його меню): ⟳ у смузі «Редагування» замінює його (правий клік — без стиснення), або перетягніть файл у чат.
- 🙂 — панель стікерів: емодзі (правий клік чи довге натискання на 👋 та інших людях обирає колір шкіри, він запам'ятовується для цього емодзі), GIF (збережені GIF), 🔍 (пошук наборів стікерів; порожній — популярні), ★ обрані й 🕒 нещодавні стікери, далі встановлені набори; ⚙ — ваші набори: порядок (↑/↓) і видалення. Правий клік на стікері: додати в обрані чи прибрати з них, переглянути набір. Клік на стікері в чаті (або посилання `t.me/addstickers/…`) відкриває його набір: усі стікери, «Додати» / «Видалити», копіювати посилання; правий клік на стікері в чаті — «Переглянути набір», «Додати в обрані», на GIF — «Зберегти GIF». Емодзі, набране саме, пропонує відповідні стікери над полем.
- Клік по фото чи файлу — завантажити в «Завантаження» і відкрити.
- Права кнопка миші на чаті: закріпити, вимкнути сповіщення, позначити прочитаним, архівувати.
- У широкому вікні інформація про чат — третя колонка поруч із чатом; у вузькому видно або список чатів, або відкритий чат зі стрілкою «назад» у шапці (Esc теж повертає до списку).
- Клік по назві чату в шапці відкриває інформацію про чат (Esc закриває): біо чи опис, посилання, сповіщення, учасники (клік відкриває особистий чат; адміни правим кліком по учаснику призначають, обмежують чи вилучають його), вкладки спільних медіа, вкладка «Історії» із закріпленими історіями людини чи каналу (чипи альбомів фільтрують їх; клік відкриває переглядач на цій історії), вийти / очистити історію / видалити чат. Посилання-запрошення, заявки на вступ, адміністраторів, обмежених і вилучених користувачів адміни відкривають із вікна «Редагувати» (олівець) або, без права редагувати, зі значка людей у шапці.
- Розмітка в полі вводу: `**жирний**`, `__курсив__`, `~~закреслений~~`, `||спойлер||`, `` `код` ``, ```` ```блок``` ````, `[текст](https://…)`; поле одразу показує її оформленою, а маркери — блідими. Над виділеним текстом з'являється панель форматування; клавіші: Ctrl+B жирний, Ctrl+I курсив, Ctrl+Shift+X закреслений, Ctrl+Shift+M моноширинний, Ctrl+Shift+P спойлер, Ctrl+K посилання, Ctrl+Shift+N без форматування.
- Клік по хештегу шукає його в чаті, по команді бота — надсилає її.
- `@` у групі та `/` на початку поля відкривають підказки (учасники, команди ботів): ↑/↓ — вибір, Enter чи клік — вставити (команду — надіслати), Tab — вставити, Esc — закрити. Кнопка «/» біля поля в чаті з ботом відкриває меню команд. `:слово` (від двох літер, напр. `:серце`, `:heart`) так само підказує емодзі.
- Над полем вводу з'являється прев'ю посилання; ✕ надсилає повідомлення без прев'ю.
- Права кнопка на «Надіслати»: в особистому чаті згори ряд ефектів (★ — Premium) надсилає повідомлення з цим ефектом; далі без звуку, запланувати або (в особистому чаті, де видно час останнього візиту) надіслати, коли буде в мережі. Повідомлення з ефектом програє його, коли з'являється вперше; клік по емодзі ефекту біля часу програє ще раз.
- У групі чи каналі, де можна писати від імені вашого каналу, круглий аватар ліворуч від 📎 показує, від чийого імені підуть повідомлення; клік показує ваш акаунт і ці канали (лише для Premium позначені) і вибирає типовий для цього чату.
- Чат іншою мовою (де Telegram це дозволяє) показує під шапкою «Перекласти …»: клік показує його повідомлення перекладеними на місці, з позначкою «переклад» біля часу (Telegram Premium), «Показати оригінал» повертає як було. ⚙ на панелі вибирає мову, «Не перекладати з …» більше не пропонує цю мову, «Сховати панель» ховає її для цього чату; «Перекласти чат» у меню чату в списку повертає її.
- «Вибрати» в меню повідомлення вмикає режим вибору; Esc виходить із нього.
- Повідомлення лише з 🎲 🎯 🏀 ⚽ 🎰 чи 🎳 надсилається як гра.
- Посилання `t.me/addlist/…` додає спільну папку; у її контекстному меню — перевірка нових чатів, а видалення пропонує вийти з її чатів.
- Налаштування → Налаштування чатів → Фон чату: галерея з сервера (зображення, візерунки, кольори й градієнти), зображення з файлу або живий фон; в інформації особистого чату → «Фон і тема чату» задає цьому чату власний фон і тему з емодзі чи подарунка.
- Налаштування → Налаштування чатів → Доступність: зменшити прозорість (суцільне скло), збільшити контраст, зменшити рух (нерухомий фон).
- Налаштування → Додатково → «Автозавантаження медіа»: що завантажується саме в особистих чатах, групах і каналах; решта медіа показує стрілку й завантажується по кліку.
- Enter надсилає, Shift+Enter — новий рядок.
- Перехід до дати: кнопка календаря в пошуку по чату або клік по даті між повідомленнями.
- Enter надсилає, Shift+Enter переносить рядок; у Налаштування → Налаштування чатів можна перемкнути надсилання на Ctrl+Enter (Cmd+Enter на macOS) і змінити розмір тексту повідомлень та щільність списку чатів (щільний, звичайний, просторий).
- Гарячі клавіші (як у Telegram Desktop): Ctrl+F — пошук у чаті (або в списку чатів), Ctrl+K — пошук у списку чатів, Ctrl+1…9 — папки, Alt+↑/↓ або Ctrl+Tab / Ctrl+Shift+Tab — попередній/наступний чат, Ctrl+E або ↑ у порожньому полі — редагувати своє останнє повідомлення, Esc — закрити верхню панель, потім чат.
- У `--demo` повідомлення з `#offline` імітує відсутність мережі (годинник → повтори → червона позначка).
- Папки: «+» праворуч від вкладок (або внизу колонки) — нова; права кнопка на папці — редагувати чи видалити; перетягування змінює порядок. Вкладки зверху чи колонка зліва — у налаштуваннях.
- Закріплені чати перетягуються мишею, щоб змінити їхній порядок (і в папках, і в архіві).
- ✎ біля пошуку — «Нова група», «Новий канал», «Контакти».
- Під час введення в пошук списку чатів під ним з'являються вкладки: «Чати», «Канали», «Застосунки», «Публікації», «Медіа». Публікації шукаються за Enter або кнопкою «Шукати публікації» (кількість безкоштовних пошуків на день обмежена); Esc очищає пошук і повертає до «Чатів».
- Ctrl+V із картинкою чи скопійованими файлами надсилає їх.
- ▶ на голосовому чи аудіо грає його; клік по хвилі перемотує, чип «1×» змінює швидкість. Клік по відео відкриває програвач: смуга перемотування, гучність, швидкість (0.5–2×), повний екран і «картинка в картинці» (маленьке вікно в куті, яке грає далі, поки ви гортаєте чати; його можна перетягнути в інший кут). Клавіші: Пробіл — відтворення/пауза, ←/→ — на 5 с назад/вперед, F — повний екран, Esc — вийти з повного екрана, потім закрити. «Відкрити в програвачі» (системному) — у меню.
- «→A» біля хвилі голосового (поруч із кружечком) розшифровує його (Telegram Premium; без нього — кілька безкоштовних спроб від сервера): поки сервер працює, крутиться індикатор, потім текст з'являється під хвилею; повторний клік його згортає.
- Довгий допис у каналі має над текстом капсулу «Підсумок»: клік ставить на місце тексту підсумок від ШІ, «Показати оригінал» у його заголовку повертає текст.
- Музичний файл відкриває панель плеєра під заголовком чату: ⏮ / ⏭ — попередній / наступний трек (⏮ після 3 с починає трек спочатку), лінія внизу панелі перемотує, далі гучність, швидкість, повтор (плейлист → трек → вимкнено), перемішування і ✕, щоб закрити. Панель лишається, коли ви перемикаєте чати; наступний трек чату вмикається сам. Клік по назві відкриває плейлист. Музика в профілі користувача — рядок у його інформації: клік вмикає її.
- 🎤 (кнопка «Надіслати» при порожньому полі) починає запис голосового; ➤ надсилає, ■ зупиняє для прослуховування, Esc скасовує.
- Права кнопка на мікрофоні — записати відеоповідомлення (камера — у налаштуваннях або `GLASSGRAM_CAMERA`).
